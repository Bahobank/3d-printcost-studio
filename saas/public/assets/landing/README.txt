ภาพประกอบหน้าแรก (landing page)
================================

วางไฟล์ภาพของหน้าแรกไว้ในโฟลเดอร์นี้เท่านั้น
(อย่าวางใน public/legacy/assets — นั่นเป็นของแอปเวอร์ชันเดิม)

ชื่อไฟล์ที่ต้องใช้ — ต้องตรงกับปัญหาแต่ละข้อตามลำดับบนหน้าเว็บ
------------------------------------------------------------
problem-01-hidden-costs   คิดแค่ค่าเส้น ลืมต้นทุนที่เหลือ
problem-02-stock          สต๊อกวัสดุไม่ตรงกับความจริง
problem-03-printers       ใช้ตัวเลขชุดเดียวคิดทุกเครื่อง
problem-04-history        ลูกค้าเก่ากลับมาสั่ง แต่จำราคาเดิมไม่ได้
problem-05-profit         ไม่รู้ว่างานไหนกำไร งานไหนขาดทุน
problem-06-scattered      ตัวเลขกระจัดกระจายอยู่คนละที่

สเปกไฟล์
--------
- นามสกุล: .svg ดีที่สุด (คมทุกขนาด ไฟล์เล็ก)
  ถ้าเป็นภาพ raster ใช้ .png หรือ .webp
- ขนาด: อัตราส่วน 1.4 : 1 เช่น 1400 x 1000 px
  (กรอบบนหน้าเว็บใช้ 420 x 300 ภาพจะย่อ/ขยายให้พอดีเอง)
- ขนาดไฟล์: ไม่ควรเกิน ~300 KB ต่อภาพ
- พื้นหลัง: การ์ดที่ครอบภาพเป็นสีขาว มี padding รอบ 12px
  ถ้าอยากได้พื้นเทาอ่อนแบบภาพชุดปัจจุบัน ให้ใส่พื้น #f8fafc มาในไฟล์เลย
  ถ้าใช้พื้นโปร่งใส ภาพจะกลืนไปกับการ์ดสีขาว

ใส่ครบแล้วบอกได้เลย เดี๋ยวเปลี่ยนโค้ดให้ไปเรียกไฟล์เหล่านี้แทน SVG
ที่วาดไว้ชั่วคราวใน src/components/landing-illustrations.tsx

ไม่จำเป็นต้องครบทั้ง 6 ภาพในครั้งเดียว ข้อไหนยังไม่มีไฟล์
จะใช้ SVG เดิมไปก่อนได้
